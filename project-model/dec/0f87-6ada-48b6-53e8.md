# Reprojection lives in an independent module, libreproj: own double-precision projections (Web Mercator, transverse Mercator/UTM, Lambert-93, geographic), no PROJ and no datum shift (ETRS89/RGF93 = WGS84 for display); vertices transformed in batches over the CPU's cores; rasters warped as a refined triangle mesh drawn by the GPU (hardware path, any graphics API, no shader), with a multi-threaded CPU warp as fallback; the map shows tiles native to the chosen projection where providers publish them, warped ones otherwise
