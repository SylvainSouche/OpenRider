# Any layer can be shown in a national system: the projections offered are Web Mercator, the layer's grid systems (marked 'native tiles'), then every national system whose area of use holds the view's centre (WGS 84 UTM only where no ETRS89 zone of that number does), smallest area first; tiles are warped where not native. In a national system the view stays within the layer's extent intersected with the system's area of use, widened by 12 degrees with native tiles (Kartverket uses UTM 33N for all Norway), 3 when warped; content outside that area switches back to Web Mercator. The Oman jump came from projecting IGN's world-wide extent (overseas territories) into Lambert-93
