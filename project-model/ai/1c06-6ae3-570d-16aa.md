# On Windows, OpenRider's application libraries (core, maptiles, app) are built static (OpenRider/mk/pre.win.mk), and every GNU-toolchain link excludes static archives' symbols from DLL exports (mk/pre.win.mk, -Wl,--exclude-libs,ALL): these libraries declare no exports, so as DLLs they exported every libstdc++ inline instantiation and programs linking them beside openrider_sdk or reproj got duplicate definitions (libapp tests, perf.tst); plugins stay DLLs with their one explicit export

> AI proposal — introduced by Claude, not the user. Not a requirement until a DEC records acceptance.
